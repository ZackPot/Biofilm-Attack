# Bio-Film Attack

A game that teaches the types of enzymes someone would find in a chronic wound through a space-invaders synthetic biology hybrid. This game is for the Eton IGEM 26-27 about chronic wounds.


## Roadmap

*  5 levels including different enzymes and bacterial biofilm's
* 10 different scientifically accurate features of a chronic wound
* 5 different weapons/scientific medicines used to save the patient
